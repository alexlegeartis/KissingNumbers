# Optional limitation of the sign layer

The64-word sign code is optimal among antipodal length10 binary codes of minimum distance3. Such a code has distance support{0,3,4,5,6,7,10}, with A0=A10=1. For binary length10 Krawtchouk polynomials take f=1+(K2+K8)/3+K10. Direct evaluation gives f(0)=f(10)=32 and f(d)=0 for d=3,...,7. Character-sum positivity gives sum_d A_d f(d)≥sum_d A_d=M, so M≤64. This does NOT exclude larger non-antipodal sign codes and is not a general kissing ceiling.
