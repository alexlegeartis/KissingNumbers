## Exact construction

Retain the21,943,640,934-point90D equator from the [hexagonal phase-layer package](../dim90-92-hexagonal-phase-layers/). For a Pless[48,24,15] word with first-three-symbol prefix p of weight w, select the explicit weight15 outer words and delete this prefix. Their signed A2-root bodies have squared norm45−3w. Add head sqrt3(f(p1),f(p2)), where f(0)=0, f(1)=1, f(2)=−1, with the third prefix coordinate zero. Head norm squared is3w, so every point has norm squared45. For91D use only prefixes000,100,200 and one head coordinate; for92D use all nine prefixes(p1,p2,0).

Different outer words have body squared distance at least45−3dH(p,q), while the heads supply at least3dH(p,q). For a fixed outer word, phase distance5 gives squared distance at least45. The phase14 code is generated by eight shifts of polynomial x^6+x^5+x^3+x+1 overF3, yielding6561 words; its shortened phase13 code has2187 words. Exact exhaustive nonzero-weight checks prove minimum5 in both linear spaces, and therefore every pair distance. Source attribution and exact generators are in `latitude_linear_phases_20261117/PROOF.md`; validity does not rely on a table entry.

Each weight1 prefix has31680 explicitly verified outer words. Each weight2 prefix has6930. No shell completeness is needed. Dense-equator cross inner products are at most21 or19.5, below22.5; sparse-equator compatibility follows from the common Pless minimum and prefix-distance inequality. The inherited published Pless minimum15 premise, generator identity and full old equatorial proof are retained. Rank or self-duality alone is not claimed to prove minimum15.

Thus91D adds2·31680·6561=415,704,960 latitude points and two orthogonal poles.92D adds4·31680·6561+4·6930·2187=892,033,560 latitude points and six orthogonal hexagon points. The old shortened phase sets are replaced, not unioned; no additional antipodal doubling occurs.
