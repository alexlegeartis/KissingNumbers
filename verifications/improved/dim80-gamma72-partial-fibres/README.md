# Clipped Γ72–E8 fibres in dimension 80

**80D lower bound: 6,228,431,712**, an increase of 325,512 over the preceding 6,228,106,200. The certificate uses 39 antipodal E8 root directions with distinct depth-six Γ72 phases. There are 27 full fibres and 12 clipped fibres. Each full fibre contributes 136,704 horizontal points per sign; each clipped fibre contributes 119,744 per sign. The base Γ72 shell has 6,218,175,600 points and the pure E8 tail contributes 240. This is a constructive lower bound, not an optimality claim.

The pinned [seven-chart construction](../dim77-79-gamma72-seven-charts/) supplies 64 automorphic phases. Distinct rays have absolute vertical dot either zero or one. Cross-chart pairs pass the whole-coset depth check. Within a chart the six depth-six phases form two triangles, with vulnerable depth-four edges only between the two triples. Orient each actual vulnerable edge towards the fibre to be clipped. In this witness there are exactly 12 such edges, each resolved by clipping one different endpoint.

A vulnerable phase difference has dependent nonzero first labels and zero second label. Such a difference coset has raw minimum eight and no raw length squared ten: a lone nonzero block would be singular; two occupied blocks with equal nonzero first labels have equal second labels and their quadratic parities add to zero; a zero first label cannot contribute a norm-four or norm-six block; three occupied blocks cost at least twelve. For a raw norm-twelve contact x to collide with the full opposing fibre, a raw norm-eight difference u must satisfy x·u=4, since then the opposing point x−u has raw norm twelve. The opposite vertical sign imposes no stronger check. Raw norm-eight differences are either one block of norm eight, with 48 exact representatives, or two norm-four blocks with equal local class, with 24 classes and all four choices of signs. The verifier enumerates the resulting exact dot tests.

The three horizontal norm-twelve types are 4+4+4, 4+8 and 6+6. A norm-six Leech parity class contains exactly two signed shortest representatives, and a norm-eight minor class contains 48, by the pinned replay. Sign-independent coordinate-block checks count all eight sign combinations for three occupied blocks and all four for two. The other pairs follow from their phase minima and the E8 root dot products. Same-ray antipodes are already vertically separated by squared distance eight. The pure tail roots are compatible with every tilted fibre by Cauchy–Schwarz.

Run `OPENBLAS_NUM_THREADS=1 python verify.py` in this directory. Requires NumPy and SymPy. It replays pinned parent sources, verifies every fibre pair, and reconstructs the clipped counts from integer coordinates.


For completeness of the short local classes: two representatives of squared norm eight in the same Leech class, not related by sign, have sum and difference in twice the Leech lattice. Both have squared norm at least 16, so the parallelogram law forces equality and hence orthogonality. There are therefore at most 24 pairs, and the replay exhibits all 48. The same argument permits only one opposite pair at squared norm six.
