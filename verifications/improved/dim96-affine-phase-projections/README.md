# Phased axis projections in dimension 96

The lower bound is **209,292,294,976**, an increase of **421,888** over the full 1170-pattern mixed triality configuration at 209,291,873,088. Every old point is retained. Append 103 six-row triality patterns, each contributing 4,096 directions. The earlier pure BCH, pure hexary, mixed-triality and all other layers are preserved.

A line of witness.txt gives the three disjoint masks for axial, even-flat and odd-flat frames, a six-digit permutation of the six axis-code coordinates in ascending physical row order, and a 12-bit XOR translation applied to the axis code *before* permuting its coordinates. The last integer on the line records a discovery statistic and is not used in verification. Row geometry, per-pattern norm squared 24, and the independent 32 even sign choices are unchanged. Coordinate permutations and translations preserve the 128-word quaternary axis code's Hamming distance three.

For two patterns sharing q active rows, r of these have equal frame. If the axis words are at Hamming distance d on those r matched slots, the raw mixed product is at most 2(q+r)-4d. Unequal frames cost at most two per row; equal frames contribute four only on identical projective axes and otherwise zero. The older support-only check used d=0. To compute the true minimum d, project each translated axis code to the common equal-frame slots, in the same physical order. The componentwise XOR of these two affine spaces is the sum of their projected binary linear spans plus the XOR of the translation vectors. The verifier enumerates its exact Hamming weights. This rescues 79 pairs against the old 1170 mixed patterns and 64 against the earlier pure-hexary modes. All new-new pairs satisfy the ordinary support bound.

All new patterns still pass independent overlap and row-amplitude checks against ordinary and paired BCH, flat RS, amplitude-four RS, grouped roots, dense Z8 and shifted Golay. The latter geometry is the same as the preceding mixed triality proof; no axes or signs in those layers were moved to obtain the rescue. Run python3 verify.py, with the standard library and assertions enabled. The two published predecessor witness files and the earlier 219 complementary six-row supports are hash-bound inputs. The verifier also reruns the inherited finite frame-geometry checks. Use the same axis order in every use of a given frame: coordinate order for the axial frame and lexicographic order of the representatives with first coordinate +1 for each flat frame. The finite explicit witness does not depend on how the candidates were computed.
