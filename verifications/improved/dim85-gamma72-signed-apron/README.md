# Signed Γ72/Zinoviev–Ericson packets in dimension 85

The final lower bound is **6,297,207,062**, **30,324** above the preceding 6,297,176,738 bound. The horizontal Γ72 core is unchanged. The antipodal 1,154-vector [Zinoviev–Ericson](https://www.mathnet.ru/eng/ppi457) tail is the same as the preceding 85D construction; its exact coefficients are in `ze99.txt`. Each signed tail direction has its own horizontal mask. The tail vectors are scaled to squared norm two. All horizontal mixed vectors have physical squared norm six, and all points have squared norm eight.

The pinned Γ72 package constructs the three complete horizontal menus of raw Leech block squared-norm profiles 4+4+4, 4+8 and 6+6. A half-phase of depth six clears the equator. Distinct first colors are safe; equal phase and first color require disjoint horizontal points unless the tails are opposite. For distinct second phases of the same first color, a horizontal pair can be too close only if their raw difference is a squared-norm-eight singleton block and their tail dot product is positive. Such a difference preserves the occupied profile, so the three checks compose. Opposite tail vectors have squared separation eight on their own. The pure tail points, with tails doubled and horizontal part zero, satisfy the angle bound with every mixed and pure point.

The first literal mask layer has 8,598,411 triple blocks (eight signed vectors each), 186,276 norm-four plus norm-eight packets and 2,359,296 norm-six double packets (four vectors each). This intermediate arrangement contains 6,297,146,330 contacts. The second mask independently chooses norm-eight signs inside the 4+8 profile and retains both norm-four signs. If the norm-four block changes, the same signed norm-eight vector in the unchanged block is forbidden. If the norm-eight block changes, the offending signed Leech inner product is exactly four, tested by the exact packed matrices. This stage adds 60,732 contacts.

With NumPy and SymPy installed, place this directory next to the pinned `dim81-85-gamma72-apn-complete-dm` package under `verifications/improved`. Run `OPENBLAS_NUM_THREADS=1 python3 -B verify.py` with NumPy and SymPy from this directory. The exact replay first proves the intermediate geometry, then the final signed 4+8 replacement. It requires the inherited sibling packages, or their parent passed as the first argument.
