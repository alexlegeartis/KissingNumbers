## Exact coordinate assembly

Start with the 196,560-point integer Leech shell generated by the verifier. Pad it by zero tail coordinates; remove exactly the base NPZ `removed_leech` rows; add its `new_points`; add the extension NPZ `free_heads`; finally add the pure-tail set below. The owner indices are certificates, not extra points. Every final vector has squared norm 32 and every distinct pair has inner product at most 16. Division by sqrt(32) gives unit vectors with inner product at most 1/2.

* **26D:** the four exact square tails are `pure_tail_points` in the extension. The older six-point irrational hexagon is omitted.
* **27D–29D:** pure tails are all vectors with exactly two entries ±4, all other entries zero, in the d−24 tail dimensions.
* **30D:** replace the ordinary 60 D6 tails by the 72 rows `rational + radical*sqrt(3)` in `pure_tail30_exceptional.npz`.
* **31D:** replace the ordinary 84 D7 tails by the 126 rows `rational + radical*sqrt(2)` in `pure_tail31_exceptional.npz`.

Do **not** add the ordinary and exceptional pure-tail sets together. Integer coefficients and radicands are stored exactly; no rounded floats enter the proof. See `source/27d_local_replacements_20261026/EXACT_CERTIFICATE_ASSEMBLY_CURRENT.tex` and the axiswise and exceptional-tail proofs.

## Reproduce

Linux, Python 3.9+ and NumPy suffice. No network, optimizer, creator search state, external shell cache, or prior PASS report is needed by the full replay.

```bash
python final.py           # derive counts only; not a geometric proof
python verify.py          # all six independent exact proofs, sequentially
python verify.py 30 31    # optional selected dimensions
```

Run without `-O`. The wrapper checks complete SHA-256 coverage, copies sources to a temporary directory, and runs the independent checkers with one BLAS thread. Each dimension has a 30-minute timeout and a checker address-space cap of at most 512 MiB. Full pair replays may take several minutes. The temporary copy prevents fresh timing reports from changing committed evidence.

The independent proof regenerates the shell from Golay polynomial 0xC75, verifies the finite binary-code properties required by `SHELL_PROOF.md`, and checks deleted membership, midpoint identities, norms, distinctness, every inserted/inserted pair, every free/inserted, free/free, free/pure and free/full-shell pair, and all pure pairs. Retained shell pairs follow the supplied self-contained three-family lemma rather than a quadratic shell scan. The final 30D/31D full replays then check the exceptional tails by exact quadratic-field arithmetic and their cross products by verified tail-pattern and coordinate bounds.

## Evidence and scope

Original independent reports are retained as historical evidence. The final 30D/31D discovery checks used pinned full-baseline incremental proofs; the packaged default full checkers deliberately remove that dependency and recompute all current insertion pairs. Their `_full_replay.json` outputs are separate from original reports. The source-preparation manifest records that the adapted full checkers had not yet run at preparation time; the branch CI and integration replay provide their actual executed status.

The verification package contains only final coordinate certificates, proofs, small evidence reports/logs and source. It excludes search caches, large runtime states and unrelated private upper-bound research. Exact proofs do not establish optimality, and numerical upper-bound experiments are not part of these lower-bound claims.
