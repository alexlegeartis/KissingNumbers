# Γ72 with 510- and 604-point antipodal tails

| Dimension | Exact lower bound | Previous repository bound | Gain |
|---:|---:|---:|---:|
| 82 | 6,269,068,246 | 6,254,779,152 | 14,289,094 |
| 83 | 6,278,746,180 | 6,265,203,518 | 13,542,662 |

Each construction retains all 6,218,175,600 contacts of the 72-dimensional Nebe lattice and replaces its preceding BW-tail augmentation. The tails are the existing 510-point antipodal code of [Ganzhinov, §5.4](https://arxiv.org/abs/2207.08266) and the 604-point code of [Bianchi, Kwon, Pappu and Zou](https://arxiv.org/abs/2606.10402), the latter using [Baker's exact coordinate reconstruction](https://github.com/karlbaker75/kissing-number-k11-604-exact-certificate). All tail geometry is verified again on the included literal coordinates. The 82D integral array uses metric diag(1,1,1,1,1,3,3,3,3,3), with norm squared 144; the 83D coordinate pairs are coefficients of 1 and sqrt(2), with norm squared 36. For both antipodal codes the verifier checks the absolute off-diagonal inner-product bound on all distinct rays.

Normalize each tail vector to squared norm two and choose a distinct (first-label colour, horizontal phase) pair for each antipodal ray. For each ray place the selected depth-six horizontal points over both signs of its tail vector. This yields norm-eight contacts. Add a pure tail point twice each norm-two tail vector. A mixed-to-pure tail dot product is at most four by Cauchy–Schwarz, and pure-to-pure is at most four by the verified tail bound.

For different first-label colours, the horizontal phase separation is at least six in squared distance, as established in the pinned Γ72 construction. Within a ray the horizontal differences lie in Γ72, with minimum squared norm eight. For two different rays of the same colour, their distinct phase difference has squared depth four; if orthogonal they already have tail squared distance four. In the nonorthogonal case a horizontal squared distance four would be the only obstruction, since all other horizontal distances are at least six and distinct signed tails have squared distance at least two. The pinned Γ72 verification shows that such a norm-four horizontal difference comes from a single raw norm-eight Leech block. It preserves the partition into the sorted raw norm profiles 4+4+4, 4+8, and 6+6. Replaying conflicts between occupied groups therefore suffices. The triple-profile optimizer groups vertices by their common first block and the two exact phase cosets; all its output groups are explicitly checked against the entire conflict edge list. No optimality of that optimizer is required.

The raw counts, before the triple-profile reallocation, are respectively (2,705,592, 64,095, 783,360) and (3,219,847, 86,857, 927,744). The triple-profile reallocation adds 51,439 and 58,476 groups, respectively. The 4+4+4 groups contribute 16 signed points and the two other profiles contribute eight signed points per group. The pure tails contribute 510 and 604 more points.

Place this directory under `verifications/improved/` as `dim82-83-gamma72-antipodal-tails`, then run `sha256sum -c SHA256SUMS` and `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B verify.py`. It uses Python with NumPy and SymPy, and a C++17 compiler (`g++`). The integer-valued short dot tests using binary64 have checked exact range; the remaining tail tests use integers, including exact signs in Z[sqrt(2)]. The previous-bound claim file and the inherited Γ72 code and witness are SHA-pinned.
