# Six- and seven-row flat layers in 91–93D

This extension replaces the 323,584-point flat layer of the preceding three variable-radius configurations. It retains every dense Z8 fiber and all 145,004,544 sparse Golay points. The replacement has 2,613,248 points: a net increase of 2,289,664 in each dimension.

| Dimension | Previous lower bound | New lower bound |
|---:|---:|---:|
| 91 | 25,915,131,904 | **25,917,421,568** |
| 92 | 34,505,066,496 | **34,507,356,160** |
| 93 | 47,389,968,384 | **47,392,258,048** |

Each six- or seven-row support has a stored parity pattern and its complement. For supports meeting in k rows, with d parity differences on those rows, every complementary choice gives inner product at most 4k−2 min(d,k−d). The exact table uses 114 six-row and 131 seven-row supports. Four projective flat axes in each four-coordinate row are labeled by the quaternary symbols.

The length-six axis code is the 64-word quaternary hexacode. The length-seven axis code has 128 words with distance four. It is generated by a binary [7,4,3] Hamming first component and a permuted simplex second component plus a phase depending on the first message. The exact checker enumerates all pairs. In each case use all even-weight sign patterns and both row-parity patterns. The squared radius is 4 times the support size, and within a parity mode every distinct pair has sufficient axis or sign distance.

Against the dense Walsh bodies, a seven-row pattern has at most four rows of the same parity, giving dot at most 22. Dense axial bodies give at most 2 per row. The dense squared radius is at least 88. The outer table separately checks all overlaps with the 993 sparse Golay supports, using dot at most 4 per shared row and the actual squared radii 80 or 88. Dense, inherited sparse and new flat points have distinct ordinary support sizes. The different row parity modes on the same support also give distinct points.

Run python3 verify.py (Node.js required). It runs flat67.cjs with the original sparse data, checks every new support and pair, and replays the three parent certificates. claims.json and verify.log contain the exact totals. The earlier 323,584 flat points are not taken in union with the replacement.

For a separate Python-only implementation, run independent.py against flat_supports.json. The output is in independent.log.
