# 21D exact Singer-symmetric hole barrier

Kevin Li’s verified 31,560 = 27,720 odd-stock +3,840 sign points, [primary paper](https://hexagonmath.org/pdf/2610.00248v1), assigns projective lines to a subset of the 4,096 words of 3-punctured extended Golay. An occupied word c must choose a line P for which c+P is omitted. If the omitted set J is an independent dominating set in the Cayley graph generated by the 21 line words, arbitrary choice of a neighboring hole gives a valid labeling: no active edge can have either incident label equal to its difference P, and equal chosen labels at the ends would imply adjacent holes after translating by that label. The published linear size-256 hole set attains 31,560.

The lines span a binary space of rank 10, verified exactly by generating all 1024 words from cyclic projective line mask 20680 (trace-zero line for the Singer cycle on F64*/F4*). The full graph has four isomorphic components of size 1024. Two distinct projective lines share one point; all 210 pair sums are distinct, since any third line can meet their union in at most two points. In one component an independent dominating set of at most 63 is enough to improve if the other three retain 64 each.

The exact replay proves NO independent dominating set of size ≤63 if invariant under the cyclic Singer shift 1 (order21) or shift 3 (order7). In the base component this is a finite weighted domination problem on 52 and 148 orbits respectively. Weight is orbit cardinality; discard loops for independence except for their role in adjacency, and an invariant feasible set is an independent set of eligible orbits whose closed neighborhoods cover the quotient. Exact branch: choose an uncovered orbit with the smallest list of eligible neighbors, branch on selecting one, forbid all its adjacent orbits; the final pruning uses only integer coverage-to-cost upper bounds. All branches exhausted (exact integer tests: 41 nodes for shift1, 67,373 for shift3), no numerical solver, no timeout. The generator check also verifies weight, pairwise intersection and exact line-span dimension.

This extends to all four components for a Singer-7-invariant global hole set since order 7 cannot permute the four cosets nontrivially. The induced odd-order affine action in each coset has a fixed point by summing its orbit in characteristic 2, so translating by it identifies the action with the base component. Therefore each of the four components must use ≥64 holes in this family. No new kissing lower bound or global 21D upper bound. Asymmetry, nonindependent dominating sets with careful separate labels, or more than one low-coordinate profile remain open. This is an exact scope separate from a preliminary bounded 7-point quotient scout, which was not exhaustive across quotients.
