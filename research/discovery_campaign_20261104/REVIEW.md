## Findings resolved before handoff

- **P2 — support evidence binding.** The initial support replay reported source and witness hashes without checking them, despite stronger README wording. A scratch source containing 26022 invalid full-coordinate supports was accepted. The checker now verifies the expected hashes, uint64 encoding, coordinate range, distinctness and weight 24 before checking blockers. The scratch source now fails with `Source hash mismatch`; the genuine certificate still passes.
- **P2 — ring coverage and comparison assumptions.** Initial ring replay established coverage only relative to its supplied family list and trusted supplied pruning baselines. It now requires exactly the intended 32 `(n,q)` families without duplicates, checks baseline source hashes, and independently reconstructs the dated comparison values. Missing-family, duplicate-family and altered-baseline tests now fail. The linear-obstruction adapter also explicitly requires the Z4 domain and nonempty constraints.
- **P2 — optimized Clifford checks.** Assertion-dependent Clifford checks could be disabled by optimized Python. The script now refuses `-O`/`-OO` before certification. The written quadratic-sign and regular-bipartite graph argument supplies the family proof behind the 16D/32D/64D bounds, rather than treating the 32D computation alone as a 64D proof.
- **P1 — exact integer rank.** The new fraction-free helper initially scaled only the tail of a row when eliminating a nonunit pivot. With out-of-order pivots this changed the span and could either increase or decrease the reported rank. Two explicit three-row counterexamples exposed it. Elimination now scales the whole row, counts the full operation cost, and passes independent dependency-sensitive rank checks.
- **P2 — constructor allocation order.** Section replay initially parsed rational normals before its dimension guard; coupled lifts initially built output matrices before dimension, pair, rank-work and coefficient-size checks. Both now enforce the relevant preflight limits before allocation. Adversarial parser/allocation tests pass.
- **P2 — coverage row and inventory integrity.** The coverage checker initially omitted the enclosing-row dimension check and could hide integrated outputs despite listing an audited recipe inventory. It now matches independently replayed dimensions to their rows and audits every `(recipe, output)` exactly once. Provenance follows reachable source ancestry instead of only the terminal operator.
- **P1 — repeated-mask overlap argument, retracted.** A zero minimum cross distance was initially treated as incompatibility of two translates. The exact counterexample has two 4096-word parents, intersection 2560, and a 5632-word union of minimum distinct distance 8, checked over 15856896 pairs. The unrestricted bound and branch-closure claim are withdrawn. Search, replay, receipts and README now restrict the 262144 bound to pairwise-disjoint translate unions and explicitly retain the unrestricted case as unresolved.
- **P2 — 96D rejection-witness coverage.** The initial replay accepted 414 copies of one valid witness without binding them to the 414 proposed triples. It now checks unique/full proposal-index coverage, functionals, permitted pair differences, vector domains, layers and source-index ranges. The duplicate attack now fails; all actual witnesses bind correctly.
- **P1 — coset search pruning scope.** A torsion-only family bound initially removed torsion vertices from mixed assemblies. Mixed requests now retain those vertices and use only justified same-colour edge cuts. This prevents an unsupported candidate exclusion; the API still returns only unverified search results.
- **P2 — bounded search/compiler work.** Correction sampling no longer allocates a 16-million-element population for a small sample, recursive clique traversal now checks cutoffs, and planner subset compilation has explicit size/work/count limits before expensive combinatorics.
- **P2 — planner implementation binding and prefix service.** Changed source/contracts or mismatched worker source manifests now discard the result before ranking. Adaptive expansion initially filled a small program cap with constructors before reaching a two-node candidate; persistent transactional prefix turns now interleave work, retaining all cursors. Checkpoint schema 2 prevents incompatible resume while old ledgers remain readable.

## Scope retained

Scheduler completeness means execution coverage of the explicitly declared finite grammar. It does not imply mathematical completeness, successful proof of every candidate, or coverage of undeclared constructions. Failed, numerical, timed-out and unverified outcomes do not become exclusions or exact rankings. The scheduler has no dimension-based family filter; operator preconditions and explicit budgets still apply.

Ring exclusions retain their stated extension domains; repeated-mask capacity pruning does not cover arbitrary masks or outer codes. The support obstruction concerns a sufficient intersection rule, not all signed spherical assemblies; the million triple/singleton trials remain sampled. The Clifford bound concerns real stabilizer states, not arbitrary Clifford or group orbits. Hashes bind selected evidence contents and do not authenticate provenance or establish novelty. No new certified record resulted.

The corrected repeated-mask replay passes under optimized Python with status `PASS_FOR_DISJOINT_TRANSLATES_ONLY` and `unrestricted_union_status: unresolved`. This scope correction leaves the primary seven-unresolved-module census unchanged. The exact overlap counterexample is retained as a regression case.

The objects/contracts layer does not replace the existing execution or verification authority. Its unavailable arithmetic/backend combinations remain unavailable. The new gluing backend handles finite exact explicit inputs; a general compressed heterogeneous compatibility oracle is not claimed. The full 96D bridge was inspected as a specialized fresh execution of the two existing checkers; its lengthy full proof run was performed by the parent campaign, not repeated in this review.

Exact target reproductions currently cover dimensions 1–8, 10, 13, 14 and 16. The other 12 dimensions retain explicit gaps. Static supplied root fixtures are separately checked against formula regeneration; imported executor ancestry is not turned into autonomous discovery. The native 13D signed construction is a known 1154-point reproduction.

The planner enumerates a declared finite language and retains failed/unsearched scope. Adaptive ordering remains a heuristic: tiny caps can still stop before useful candidates, and no general search-efficiency guarantee is established. Checkpoint summaries are historical receipts; exported candidates must be independently verified before use. The coset API's forecasts and sampled upper estimates never become exact spherical facts. Raw quadratic coordinates lie in Q(sqrt(3)); per-point normalization can require additional radicals, while the checker reduces its inequalities exactly.

All reviewed blocking proof and resource defects above are resolved. No new certified record resulted; unrestricted constructions and the explicitly listed coverage/research gaps remain open.
