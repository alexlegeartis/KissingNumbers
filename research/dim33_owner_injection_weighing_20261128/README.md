# A 33D whole-bank obstruction and signed weighing-frame packets

The incumbent construction has 370,556 points. This note does not improve that lower bound or establish an upper bound on the 33D kissing number. It proves a finite nonaugmentation theorem for one class of changes to the incumbent, and gives a different signed packet construction not limited to that class.

The exact input is the [pinned 33D witness](https://github.com/alexlegeartis/KissingNumbers/blob/abda686407447f0f2770d43077bf2b95fb8c29bf/verifications/improved/dim33-root-star-exchange/witness.npz). Vectors have squared norm 32 and admissible inner product at most 16. The stock is 131,072 dense rays, 1,837 complete 128-ray parity banks on octads, and 4,348 explicit sparse rows. An old owner of a new support is an incumbent full-bank support meeting it in at least five coordinates. Here a clean replacement keeps the dense stock and all explicit sparse rows and uses complete incoming banks. 

## Fully exact geometric injection, for every size of clean full-bank trade with ≤3 owners per new support

Any five-coordinate set is contained in at most one old bank, because distinct old 8-masks have intersection at most four. The exact list of owners of S is the union of all its 5-face owners. For a full incoming bank, every fixed old explicit row clears iff the absolute sum on S is ≤8, irrespective of bank parity; an old sparse row with a zero inside S attains its full unsigned maximum by tuning parity there. The only literal rows without a zero in S are individual signed octads on that very support, for which both parity options have a forbidden dot. Dense and root compatibility follow automatically from `2×8≤16`. Call candidates passing this condition clean. Fixed octad packing incidence and tests reproduce 2,369 clean new supports, partitioned 0/109/659/1601 by owner cardinality 0/1/2/3. All supports before sparse screening by owner cardinality 0..3 are 197/219/1120/2971.

In any profitable clean whole-bank exchange pick its selected incoming supports and every necessary old owner. Remove a selected incoming support that is the only one hitting some owner, and remove that owner (and any others becoming unused) from the deletion list. Profit (#incoming minus #owners) does not decrease. Thus there is a profitable core in which every used owner belongs to at least two incoming supports. For a potential support S and owner b of it, some **other** selected S' must contain b as owner and be compatible with S (overlap≤4). Simultaneously choose one witness for each owner of S, allowing one witness to serve multiple owners; those witnesses must be mutually compatible because the same profitable core contains them. Therefore one may delete any support for which this necessary local choice does not exist, iterating to closure. The exact six deletion counts are 948,156,66,7,4,1; 1,187 remain. The compatible witness search chooses up to three supports for each S; it is not a random selection.

There is now an explicit **assignment** `S ↦ b(S)∈owners(S)` of all 1,187 survivors such that any two different supports assigned the same old b have intersection at least five. Therefore the assignment injects *any* compatible selection into its needed owners: at most its own owner count, contradicting positive profit. This excludes all sizes of clean full-bank assembly in the stated per-incoming ownership scope, including every bicycle of arbitrary length made solely of one/two-owner clean supports and every clean ≤3-hyperedge extension. It is not a certificate for four-owner candidates, sparse changes, arbitrary sign refills, or global 33D. In fact the current full clean ≤4 inventory has 6,838 and the ≤5/≤6 inventories 17,463/41,717; the first finitely verified assignment was for ≤3 only. Raw ownership complexity does not itself rule out more general exchanges.


## Distinct positive construction mechanism: two-twin weighing frames and fractional whole-bank charges

Fix a set P of four common sign coordinates. Use a residual weighing basis W with orthogonal rows, each having four nonzero ±1 entries. Let W' be another orthogonal basis on the same residual axes such that every absolute cross-inner-product is ≤2. For each sign prefix h on P, take every row ±w of W if prefix parity is even and every ±w of W' if odd. Vector coordinates are scaled by 2. At same prefix common contribution4 (unscaled) and residual dot≤0, at neighboring prefix common dot2 and residual≤2, at distance≥2 common dot≤0 and residual≤4. Thus a residual frame of rank r gives exactly 32r simultaneous explicit rays. Old ordinary complete K banks sharing P supply 4K residual basis axes (32×4K rows); getting ≥4 more residual axes or summing weights across several independently matched frames could win +128. This is a signed family beyond uncharged whole banks, so no contradiction with ownership certificate above.

A concrete W(6,4) has three disjoint coordinate pairs A,B,C: use two rows on each of A∪B, A∪C, B∪C, with local directions on each pair ((1,1)) and ((1,-1)), one assigned to each of that pair's two chart incidences; use both relative signs between local factors. Orthogonal verification from disjoint/opposite local factors. Flip one bit in each physical pair to produce W'. Each same-chart cross dot is zero, each distinct-chart intersection two and cross absolute ≤2. Each of three 8-supports carries exactly 64 new rows, total 192. Equivalent simple algebra: for every common prefix and the two disjoint residual pairs R,S, require `parity(R) + parity(P) = alpha_R` and `parity(S) + parity(P) = alpha_S`, choosing opposite fixed character at each pair across its two chart types. All signs in that affine [8,6,2] class are present.

W(7,4) uses the seven cyclic shifts on Fano complements of a difference set with four support positions `{0,1,2,4}` mod7 and signs (-,+,+,+), respectively. Distinct rows intersect in two terms, one mismatched (directly checked mod7), hence mutually orthogonal. Choose W' by a diagonal flip on any non-line triple of the primal Fano triangle system. Each support complement contains 1,2,or3 of the flips (no line contains the triple); same support cross absolute≤2, all different supports intersect2. Gives 224 explicit rows for seven residual axes. Higher weighing twin frames / arbitrary residual signed matching, instead of forcing whole W6 or W7, are a separate positive research lane.


## Replay

Download the pinned witness linked above. Run the included checker with Python and NumPy:

```sh
python verify.py witness.npz assignment.json
```

The checker validates the witness SHA-256, reconstructs the ownership and clean support list, peels only supports that cannot belong to a profitable subfamily, and verifies the assignment independently of how it was found. The 1,187 assignment rows are pairs of integer support mask and zero-based old-bank index.
