Distinct h modulo 8D_n or differing r prevent b coincidences by saturation; within a single affine fibre they are injective. Same quotient class and same r must never be duplicated across source shells: they are exactly the same b set. This is why the torus, not independent raw-profile labels, is the correct geometry.

## Why the attractive ~1.26B optimistic estimates do not certify a record
In the fixed pure-Leech D4 family of the project proof, promising templates with two r=128 anchors require both norm8 and norm10 difference shells absent in a deep-hole torus class δ64. All three deep holes are represented by h=(8,0,0,0) or h=(4,4,4,4) with one of the two total-sign parities. The normal p=h/4 has norm4. In one pure Leech block Γ72 raw components use half the orthogonal triple norm. Thus the block vector c=√2 p has norm8 and lies in the actual Leech lattice: it is √2 times an integral D4 vector ((2,0,0,0) or a four-sign tetrad). If its norm8 Γ72 difference class is empty, f8(c)=0. Under the polarized Leech description, with g=cB mod2, g=0 would force f8(c)≥96, so g≠0. There are 24 type2 minimum parity classes of a over g. Each pairs with a nonzero even b class of the same B-value. If any paired b class were type2, representatives of norms4,4,8 would make a norm8 vector, contradiction. Therefore b is type4 and has norm8 representatives; choosing a4,b8,c8 yields an actual Γ72 norm10 vector with exactly that normal profile. This **pure-Leech dichotomy** forbids double emptiness. Inherited parity classes and polarization are proved in the public package:

This shows short differences cannot be excluded by absence; it does not assert a short difference between any two particular endpoint families must be realized. General mixed-block normal systems are not covered by this parity argument.
