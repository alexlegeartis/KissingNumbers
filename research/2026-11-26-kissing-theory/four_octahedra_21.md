# 26D: four six-row octahedral modules, a 21-point sufficiency gate

This is a new exact reduction, not a verified new record. External baseline Rustem Takhanov v0.2 at 77f0860 remains 201,212. Source 200,864-point exterior and ten orthogonal axes are as in the previously verified four native six-coordinate charts. Starting skeleton consists of 20 signed axes and 224 signed tetrad rows. Four original five-coordinate chambers are A=(0,1,2,3,9), B=(0,3,5,7,8), C=(1,2,4,6,8), D=(4,5,6,7,9). Pair A,D shares only old tail 9; pair B,C only tail 8. Other pairs share two regular coordinates, no old tail.

Within each chamber select hot index 0 (A,B) or 4 (C,D), and place the other three regular indices in increasing order. Let T be the old tail, S the other tail. Set denominator sqrt(10089). Use hot, old tail and new tail numerators 50,49,2 respectively. On the other three axes place any of
+/-24*(1,2,2), +/-24*(2,1,-2), +/-24*(2,-2,1).
These are six vectors per chamber. Their regular vectors are an orthogonal tripod and its negatives, each norm squared 9*24^2=5184; the hot and tail norm squared is 2500+2401+4=4905. Thus the total norm squared is 10089 and the within-chamber dot numerators are at most 4905<10089/2. Coordinate cap uses 4*50^2=10000<10089. The exact six-coordinate exterior left-side numerator is 50+5*24+2*2=174<2*sqrt(10089).

For each module only its hot mixed tube fails: 50+49+2=101>sqrt(10089), but all other regular amplitudes are <=48 with 48+49+2=99<sqrt(10089). Thus on tetrad [0,4,8,9], modules A and B each remove sign masks {0,2}, and C and D each remove masks {0,1}. All four modules jointly delete exactly three rows, no others. All 20 axes remain.

Within pair A,D and pair B,C, the cross dot numerator is 49^2+2^2=2405. Between any of the other four pairs, two body positions and both distinct tails can overlap. If one position is hot for both (A,B or C,D), upper-bound the cross dot numerator by 50^2+48^2+2*49*2=5000<10089/2. If no shared hot, every common body magnitude is <=48, giving upper bound 2*48^2+2*49*2=4804. These are all module pairs.

The same 5D code X can now be copied into all four chambers, with the same hot coordinate and old tail conventions. Coordinates are required clipped componentwise by 1/2 and X must be a unit spherical code at threshold 1/2. Its additional and only condition from the module of its own chamber is
50u+49v+24 max{|r1+2r2+2r3|, |2r1+r2-2r3|, |2r1-2r2+r3|} <= sqrt(10089)/2.
The old/global exterior is automatic by the native 6D lemma with alternate tail zero; all tetrads have at most two positions in each chamber, and the other copied chamber codes likewise overlap at most twice. With another module sharing two regular positions and using the other old tail, the worst copied-row dot is <=(50+48+2)/(2 sqrt(10089))<1/2. With the opposite module and same old tail only the old tail is common, automatically safe.

Thus if a 21-point code X satisfies the single explicit cutoff, one gets 200864+20+224-3+24+84=201213, beating the pinned baseline by 1. Any code of size 22 yields 201217. Old 26-row T is not such a witness: exact enumeration of all 3840 signed permutations gives max retained 19 (24 orientations), with retained-count histogram 11:264,12:336,13:372,14:588,15:972,16:828,17:360,18:96,19:24. For one 19-point orientation p=[1,0,3,4,2], signmask=1, a floating vertex enumeration over 324,632 five-boundary sets of the caps/module/19-row incumbent inequalities found max squared norm ~0.799595, so just adding two to this fixed starting pose is not the strategy. This last numerical test was diagnostic only; none of these claims bounds the full 21-point problem.
