## 33D: no gain from all complete shortened dense cosets with one–three marked coordinates, even with arbitrary real radius-preserving tags

Use the same literal binary [32,17,8] Cheng–Sloane generator as the `dense_generator` array in `verifications/improved/dim32-35-signed-layers/nonantipodal33/certificate33_370408_explicit.json` in KissingNumbers. This is the original 131,072-point dense stock in 33 coordinates with final unused coordinate. For m marked coordinates, C_M is the shortening by those coordinates. Its parity-check map in the remaining coordinates consists of the unmarked columns of the original 15×32 syndrome map H. Their rank is 15 for all m≤4 by the verified radius≤7 statement below. Thus a **complete** coset contains exactly 2^(17−m) members. A coset tag is any fixed real vector h of norm²=m in the m+1 marked/padding coordinates, independently chosen for each complete body coset. Body entries stay ±1 on other coordinates. Distinct body cosets s,s' have minimum distance d equal to the shortest representation of s+s' by unmarked H columns. Their exact cross condition is h·h'≤m+2d−16, since highest raw body dot is 32−m−2d and threshold is 16. No two tags with the same coset are possible for m≤4; d=0 would demand h·h'≤m−16<−m. The original code occupies exactly 2^m cosets because its ratio to the shortened subcode is 2^m.

Coverage assertions are integer, not solver output. Enumerate for each of 32,768 syndromes all distinct support masks of weight ≤7 (4,514,873 total). A deleted set M makes all these unavailable precisely when it hits every support in that row. Recursive branching on the first remaining unhit support proves there is no hitting set of size ≤4 for any syndrome. For weight≤6 and a two-deletion set, every hitting pair must hit the first support, and its remaining position must hit the first support missed by that first chosen position. The implementation certifies all 496 pairs (i,j) admit only the two syndromes H_i,H_j at distance 7, and exactly those two.

* m=1: parity of the weight of a representing support is intrinsic since C consists of even words. Within each parity class, d≤6, so h·h'≤−3 contradicts norm²1. Hence at most 2 whole banks.
* m=2: for each label at most two others have d=7. At d=6 the tag must be its exact negative; at most one such additional neighbor exists, because equal tags on two different cosets would require d≥8 (exclude by radius≤7); d<6 impossible. This proves at most 4 banks.
* m=3: within one parity class d≤6 gives pairwise dot≤−1. Summing norms, k points give 0≤3k−k(k−1), hence k≤4, at most 8 banks total.
* m=4, **flat tags only**: tags are ±1 in four of five coordinates and zero in one. Each parity class is a nonpositive-dot code in R^5. If it has ≥9 vectors, decompose its Gram matrix by negative-dot connectivity. Each component is either positive definite or has rank one less than its size (irreducible nonnegative matrix/Perron applied after a diagonal shift). Since ≥4 components would have to be singular and with no antipodal pair each singular component has ≥3 vertices, rank would be ≥8. Thus there is an antipodal pair; every other vector is orthogonal to that pair, and a flat tag with a different missing coordinate has an odd inner product, never zero. All in a single R^4 and bounded by the orthoplex 8. At most 16 banks.
* m=4 also cannot **append** anything to the original 16 full banks even with real tags: quotient distance to its punctured body code is ≤4, verified for all 35,960 mark sets. At d≤4 a new tag must be an exact opposite old tag, which coincides with a different original tag; the latter would need d≥8. This does not exclude rearranging all original tags with real m=4. Each stated case is bounded **even after dropping all sparse constraints**; in those cases the dense side alone at best ties the old count. There is no replacement gain to finance nonnegative sparse deletions. For prospective m≥5 one must use actual signed sparse charge; a sufficient zero-charge interface for any given existing sparse row is total body/marked l1≤16 and every marked head coefficient ≤1. Do not assume this check covers every exceptional row.

## 26D: deleting the entire old axial layer still does not permit a vacant midpoint-family ray in the old D2 palette

Exact [original certificate](https://github.com/k-nic/KissingNumbers/blob/77f0860bf93a745140e6e25481d3f60773b11441/version2/certificates/data/d26_certificate.npz) SHA256 35fd8143cf0c7e6b0146719485e00c86952cbd5e404c7881c5f6b92fa25b21ec. This complements [Lower92](https://github.com/alexlegeartis/KissingNumbers/commit/7bd7c20a3ad9da79e290786e31076a6923996786): that result lets original midpoint tails rotate continuously while retaining the axial layer. This new statement drops every one of 192 axial rows but restricts existing midpoint tails independently to their two possible D2 lines. Existing 4,416 midpoint bodies, pairedness, rational 104 rows, and radius²32 retained. Candidate body b=(a+b')/2 takes all distinct pairs of deleted Leech endpoints with dot64, different from the old bodies. Its arbitrary real tail t has norm²32. Equator-safe by midpoint convexity; pure (±8,±8) constraints automatic since ||t||₁≤8.

Two existing bodies with cross dot>32 must occupy opposite D2 lines; all such edges are between opposite original colors (source is already a packing), so valid color assignments correspond exactly to flipping connected components. Out of 18 connected components there is a 4,096-vertex giant pinned by its rational interactions without reference to any axis/pure row. In this giant the maximum body dot for each color gives caps on |4(tx+ty)|, |4(tx−ty)| respectively. With doubled body coordinates those caps are H_c=min(64,128−max(2b·b_old)), requiring H_0²+H_1²≥4096. The new replay certifies 367,270 distinct vacant candidates; 2,432 clear this cap; 2,176 fail the remaining orientation-independent midpoint dot cap, leaving 256 for exact circle checks. On the new-tail circle, each body/color inequalities and each rational inequality is affine-linear in the tail; every OR over component flips is a union of closed inequality sets. At all exact roots on the circle of all these walls, the cell boundaries and isolated points are tested. If all walls are absent or an entire circle qualifies, (4,4) suffices; otherwise every nonempty closed feasible arc has an endpoint in the finite list. For wall 2u·t=h the exact points are (h u±J u √(128||u||²−h²))/(2||u||²), allowing BigInt comparisons. There are 6,848 checks, zero feasible.

## 26D: varying both tail coordinates at radius 8 while retaining original axial frames and pinned midpoint component

Each old signed axial slot is a complete signed 24D orthonormal basis scaled by 8 (48 points with body norm²64), visible in source. We allowed removal of any pure tails, ignored all rational rows except their pin of the giant, and allowed component flips respecting it. We attempted a new radius-8 tail (any orientation, not just diagonals) on either (a) any signed tetrad body with nonzero ±4; or (b) any even-sign-change 16-site uniform ±2 body on original vertical frame's support J. Tetrads clear the full equator by direct type bounds; blocking argument below does not assume anything about equator for either class, so it also remains valid independently of prospective equator compatibility. There are 85,008 projective tetrads and 16,384 projective even-sign 16-site bodies. Against the two antipodal axial bodies let D_i=max |body dot|. Their positive and negative head-axis directions force |t_i|≤(64−D_i)/8. The census shows one can satisfy t²=64 only for D_0=D_1=16, for 12,544 plus 256 projective lines. Then |t_i|≤6, but since t²=64, |t_x|+|t_y|≥6+2√7. The aligned midpoint color (same-sign t coordinates for Q=(4,4), opposite for Q=(4,−4)) contributes ≥24+8√7, so the remaining integer body budget is at most 18. All surviving 12,800 projective lines, both body signs, both colors, have a giant body dot ≥19. Thus not even one ray from these natural full body classes fits, before paying any pure poles.

The next 26D route must alter body families, midpoint radii or head palette jointly, or pay old axial frames rather than just pure poles. A potentially useful upgrade is a real support-function lower bound for the two centrally symmetric exact tight-frame slices of the giant; each has 2,048 bodies of norm²96 and unnormalized second moment 8192 I. This alone gives support≥16 for norm²64, below the needed ≈19. This is not yet a theorem excluding *all* continuous new body directions.

### A fully continuous high-tail obstruction

With both old axial orthoplexes and the rationally pinned midpoint giant retained, **there is no non-original ray with arbitrary real body and tail norm²≥78**. Allow arbitrary removal of pure tails and every otherwise legal D2 flip. Literal replay verifies each color in the giant consists of 2,048 distinct centrally symmetric raw-norm²96 bodies with frame matrix 8192 I. Consequently for every new body b of length x, the maximum positive cross dot against each color is at least 2x (by mean square and antipodality).

Set a=8−x/√24. The signed old axial frames imply |t_i|≤a by Parseval: for each individual axial frame the largest absolute body dot is ≥8x/√24. If x=0 these caps force the four original pure points. If 0<x≤√50 then ||t||²=128−x²≥78>a², and the least possible |t_x|+|t_y| for a circle clipped to |t_i|≤a is a+√(128−x²−a²), because the sum on a quadrant arc is smallest at one endpoint. The matching-sign midpoint color has tail dot 4(|t_x|+|t_y|); its antipodal tight frame supplies a body dot ≥2x. This exceeds 64 because 16−x/2−a is positive and

    128−x²−a²−(16−x/2−a)² = x[8−(4/3−1/√24)x] > 0.

For the last strict sign, √24<49/10 implies 4/3−1/√24<166/147, and 50(166/147)²<64. This is a continuum bound, independent of the 12,800 finite body checks. It does not cover the remaining head radius interval from norm²64 to 78 for arbitrary real bodies or any approach that redesigns the two old axial frames.
