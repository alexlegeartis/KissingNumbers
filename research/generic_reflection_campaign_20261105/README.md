# Reflection exchange campaign, 2026-11-05

This is a reproducible benchmark for a finite geometric search, not a universal search or a claim of a new record. The operator generates rational reflections of an existing configuration, then searches for compatible exchanges against the source. The solver's selected configuration is independently checked with exact arithmetic. Restricted candidate pools cannot rule out better constructions outside those pools.

From the repository root, build seeds with `python research/generic_reflection_campaign_20261105/build_small_seeds.py`, `python research/generic_reflection_campaign_20261105/build18_seed.py`, and `python research/generic_reflection_campaign_20261105/build_leech_sections.py`. For dimension 17 first run `python research/mixed_tier17_eval_subgroup_20261105/prepare.py` and `python research/mixed_tier17_order8_20261105/prepare_negative.py`, then `python research/generic_reflection_campaign_20261105/build17_seed.py`. Seeds for dimensions 19–21 are included as data. The 21-dimensional seed contains 31,560 points, below the locally documented 31,688 benchmark; an improvement on this seed alone is not a record. The 22-dimensional seed is a valid 49,896-point Leech section, not the invalid scratch seed previously investigated.

Run `python research/generic_reflection_campaign_20261105/run_small.py 12 --axes 4 --candidates 60 --seconds 8` and change the dimension to any integer from 12 through 23. Large dimensions and more axes may require considerable memory and time. For 22 or 23, start with one axis. Seeds are known configurations, so success reproducing their sizes is a control, not independent rediscovery. Compare any larger certified construction against current literature and project records before claiming novelty.
